# RO3「GVG Emperium 攻城战」实机影片公开

日期：2025-10 | 来源：RO3 官方 Facebook

## Emperium Showdown 影片发布

RO3 官方发布了首支 GVG「Emperium Showdown」完整实机影片，展示了 100v100 大规模攻城战的完整流程。这是继首支预告片后最详细的 GVG 玩法演示。

## 影片亮点

- **百人同屏**：100v100 真实战斗场景
- **攻城器械**：攻城车、云梯、炮台等器械实机演示
- **Emperium 核心**：公会水晶攻防战
- **职业配合**：坦克开团、输出集火、治疗保人
