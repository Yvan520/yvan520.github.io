# RO3三测来了？我把台服消息全扒了一遍

最近RO3的消息突然多了起来。先是5月底官方发了第一篇开发者日志，承认"PC版做得不够好"正在重做，紧接着B站上就冒出了一堆新的实机演示视频。作为一个从RO1玩到现在的老玩家，我觉得有些信号值得认真看看。

## 开发者日志说了什么

5月28号那篇日志信息量不小。官方承认了之前测试的问题——PC端的UI和操作手感确实不行，跟手游版拉不开差距。他们现在的做法是"重新制作PC版UI和特效"，目标是把PC版的打击感和操作体验做到真正的PC级别。

我看完的感觉是：Gravity这次确实是认真的。之前RO1、RO的各种IP手游版本都被人吐槽"换皮"，RO3从立项到现在折腾了这么多年，他们应该也清楚，再端出一个半成品出来，这IP就真毁了。

日志里还提到PC版的技能特效、战斗反馈都在全面升级。说实话，从B站上那些新视频来看，确实比之前的好不少，特效光效更扎实了，技能释放的顿挫感也在往端游的感觉靠。

## 三测到底什么时候

目前最靠谱的猜测是2026年下半年。台服先开，国服还要等版号。B站上好几个UP主都提到了"2026下半年台服三测准备中"这个信息，虽然官方没有官宣具体日期，但多方信息指向这个时间点。

还有一个值得关注的点：官方Discord在6月初已经开放注册了。一般来说，Discord开服意味着运营团队已经到位，社区预热正式启动，距离测试开启不会太远。

## 三测会有什么新内容

根据目前能看到的线索：

**PC端全面重做**。这是三测最大的变化。之前二测的PC版被骂得挺惨，这次如果不把PC体验做好，那RO3在国际市场上基本就没戏了。PC端是RO系列的基本盘，端游老玩家不会接受一个"手机版放大"的PC体验。

**新副本和玩法**。开发者日志提到他们在开发新的副本机制，配合赛季制的内容更新节奏。三测可能会展示更多GVG和攻城战的内容，毕竟"100v100"一直是RO3的宣传重点。

**职业平衡调整**。从陆陆续续流出的实机视频来看，部分职业技能和动作效果有调整，三测可能会有新的职业平衡方案。

## 我的真实看法

说实话，RO3这个项目的开发过程挺曲折的。从最早的概念公布到现在，来来回回改了好几版。但我反而觉得这是好事——如果Gravity随便端个东西出来圈钱，这游戏我反而不想玩。他们愿意花时间重做PC端，至少说明在乎口碑。

现在最大的变数还是国服。据说是已经拿到版号了，但2027年第一季度才上线。台服这次三测应该比国服早不少，想提前体验的可以去关注一下台服的测试报名。

另外一个值得关注的是赛季制能不能在中国市场站稳。国内MMO玩家对赛季制的接受度其实不错（看看逆水寒就知道了），关键在于RO3的赛季重置规则能不能让玩家觉得"公平"而不是"白练了"。目前来看官方在这个问题上挺谨慎的，等级重置但外观和成就不重置，算是一个折中方案。

## 总结

三测应该是2026年下半年的事了，台服先来。PC版重做是最值得期待的变化，如果这次端游体验能到位，RO3还是很有竞争力的。毕竟在现在的MMO市场里，一款真正同时做好PC和手机端、有RO血统的新作，确实没几个竞品。

我会持续关注测试消息，有新的信息会第一时间更新在这里。
