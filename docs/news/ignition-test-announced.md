# RO3「启燃测试」6月25日开跑！台服招募即日开放

> 2026-06-05

今天巴哈姆特发布了RO3的重大消息：台港澳地区的「启燃测试」正式确定，6月25日到7月2日举行，今天就开始招募了。这个测试等了大半年，总算来了。

## 测试基本信息

- **测试名称**：启燃测试（技术测试）
- **招募时间**：即日起 ~ 6月23日 18:00
- **测试时间**：6月25日 ~ 7月2日
- **测试平台**：PC + 手机（跨平台互通）
- **测试性质**：免费、删档测试
- **报名方式**：官网预约，审核制

这次测试是删档的，主要是做技术验证，不是最终上线版本。官方也说了，测试期间会集中开放内容做压力测试，节奏不代表正式上线后的情况。

## 这次测什么

从巴哈姆特的报道来看，这次测试有几个重点值得关注：

**PC界面大改**。之前测试被吐槽最多的就是PC版UI太手游化，这次专门加了"高自由度使用者介面"，可以自己调整界面布局和操作方式。看得出来官方确实在按开发者日志说的那样重做PC体验。

**五人MVP副本**。以前RO的MVP都是野外抢的，这次改成五人副本形式，每个MVP有专属机制和行动模式。这个改动其实挺大的，等于把MVP从"抢怪"变成了"打本"，对休闲玩家更友好。

**十人副本**。分为普通和高难度，强调团队配合和职业分工。十人本在RO3里一直宣传得比较多，这次终于能实际体验了。

**核心养成系统**。天赋、装备、卡片这些经典系统都会开放验证，可以搭配不同的流派玩法。还有动态天气系统也会实装。

## 怎么看这次测试

这次测试离上次先锋测试隔了大半年，官方说是用这段时间根据玩家反馈做了大量调整。从开放的内容来看，PC端的优化确实是重点，这可能直接决定RO3在端游玩家心里的第一印象。

对玩家来说，这次测试最大的意义是可以实际摸到游戏了，尤其是PC版的操作手感、副本设计质量这些，看视频和亲自玩是两回事。如果你对RO3有兴趣，建议先去官网预约，审核制的话早报总比晚报好。

## 国服呢

国服仍然要等到2027年第一季度，比台服晚不少。想提前体验的可能要考虑玩台服测试了。不过删档测试嘛，主要就是体验一下游戏本身，不用太在意进度。
