# 七大职业立绘与美术设定图首度曝光

日期：2026-03-04

- 角色发丝、服饰纹理清晰可见
- 肌肉线条与动作姿势自然流畅
- 场景从 2D 全面提升到 3D
- 动态天气系统 + 昼夜循环
- 经典场景高画质重制（普隆德拉、梦罗克等）
- 新增「时序之庭」等多元宇宙场景
