# GRAVITY提交SEC文件：RO3全球服2027年，中国2026年Q4

根据GRAVITY于2026年3月15日向美国证券交易委员会（SEC）提交的文件，RO3的全球发行计划进一步明确：

- **中国服**：2026年第四季度上线，由上海热血网络运营
- **全球服**：2027年正式发行
- **日本服**：由GungHo运营，时间待公布

这是官方首次通过SEC文件正式确认发行时间表，标志着RO3的开发已进入最后冲刺阶段。
