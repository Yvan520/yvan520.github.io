# RO3 全球发行计划更新：国服2026年底，全球服调整至2027年

**2026年5月21日**

## 发行时间线调整

根据GRAVITY于2026年2月提交给美国证券交易委员会（SEC）的最新财报文件以及2025年Q4投资者简报，《仙境传说3》（RO3）的全球发行计划已做出重要调整：

| 地区 | 预计上线时间 | 运营商 |
|------|------------|--------|
| **中国大陆** | **2026年第四季度** | 上海热血网络（Rexue） |
| **全球服** | **2027年** | Gravity Game Vision / JoyMaker |
| **日本** | 待公布（与全球服同步或稍晚） | GungHo Online Entertainment |
| **韩国/东南亚** | 2027年 | Gravity Game Vision |

## 日本服代理确认

2026年2月13日，GungHo Online Entertainment（《智龙迷城》开发商、RO日本服运营商）正式宣布获得《RO仙境传说3》在日本地区的代理权。日本版本可能会与全球版本有所差异，由GungHo独立运营。

## 全球服支持信息

- **服务器所在地**：欧洲、美国、新加坡
- **时区**：GMT+8（北京时间）
- **支持语言**：简体中文、繁体中文、英语、韩语、日语、泰语、印尼语
- **首发地区**：台湾、香港、澳门、泰国、印尼、新加坡、马来西亚、菲律宾、韩国、日本

## 先锋测试回顾

RO3于2025年8月进行了首次Pioneer Test（先锋测试），为限量不计费删档测试，仅限PC平台，覆盖东亚及东南亚地区。测试内容包括：

- 六大职业基础技能与战斗
- 普隆德拉等经典场景3D重制
- 动态天气系统与昼夜循环
- GVG公会战原型测试

## 后续展望

虽然全球发行推迟至2027年，但国服有望在2026年底率先上线，这意味着中国玩家将最早体验到这个备受期待的RO正统续作。我们将持续关注国服测试进度，第一时间为大家带来最新资讯。
