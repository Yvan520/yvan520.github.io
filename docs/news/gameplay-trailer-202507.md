# 首支完整实机预告片公开

日期：2025-07-31

Gravity 与 JoyMaker 正式发布 RO3 首支完整实机宣传片，片长 3 分钟，展示从初心者到进阶职业的成长历程，以及多种核心玩法画面。

## 预告片看点

- **经典职业回归** — 骑士、猎人、十字军等经典职业实机战斗展示
- **十人副本** — 强调互动机制的副本玩法首次亮相
- **GVG 公会联赛** — 大规模公会战画面
- **普隆德拉、梦罗克**等经典场景以全新 3D 美术重制
- **多元宇宙**设定片段

官方在预告片描述中写道：

> 你是否还记得踏进米德加尔特的第一步？是否还记得普隆德拉南门外的聚散离合？今天，我们的故事翻开新篇章。

## 先锋测试同步招募

伴随预告片发布，官方同步开启「先锋测试」招募，面向台港澳、韩国、泰国、印尼、新加坡、马来西亚、菲律宾等地区的玩家开放限量测试资格申请。
