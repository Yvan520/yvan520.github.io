# 投稿与纠错

本攻略站由热爱 RO3 的玩家维护，内容持续更新中。欢迎你参与进来！

## 如何贡献

### 纠错反馈

发现攻略有误、链接失效、信息过时？请在 Discord 联系站长。

### 投稿攻略

你有独特的游戏心得、职业玩法、技巧发现？

目前接受的投稿类型：
- 职业加点方案
- 配装搭配推荐
- 副本/GVG 实战技巧
- 赚钱/练级心得

请加入 Discord 联系站长投稿。

## 内容规范

- 投稿需为原创或经过验证的信息
- 请注明适用的版本号
- 数据准确、逻辑清晰

## 感谢

每一位贡献者都会在页面中署名致谢！
