# 卡片大全

> 测试服数据尚未公开，以下为基于 RO 经典设定的卡片系统介绍。正式上线后将持续更新具体卡片数据。

## 卡片系统介绍

卡片是 RO 系列的经典系统，可插入装备孔位获得额外属性加成。

### 卡片部位

| 部位 | 可插卡装备 | 说明 |
|------|-----------|------|
| 武器卡 | 武器 | 攻击相关效果（增伤、属性附魔等） |
| 铠甲卡 | 铠甲 | 防御/生存相关效果 |
| 披肩卡 | 披肩 | 回避/减伤相关效果 |
| 鞋子卡 | 鞋子 | 移动/恢复相关效果 |
| 头盔卡 | 头盔 | SP/属性相关效果 |
| 饰品卡 | 饰品 | 特殊效果 |

### 卡片品质

| 品质 | 说明 | 掉落来源 |
|------|------|----------|
| 白卡 | 普通怪物卡片，基础属性 | 普通怪物 |
| 蓝卡 | 精英/BOSS 卡片，强力属性 | 精英怪/MVP |
| 紫卡 | 特殊活动/副本卡片 | 限时活动 |
| 金卡 | 赛季/顶级副本卡片 | 赛季奖励 |

## 卡片搭配原则

1. **同类叠加**：多张同类卡片效果相加
2. **属性克制**：根据练级地图选择对应属性卡
3. **BOSS 对策**：针对 BOSS 特性配置对应卡片
