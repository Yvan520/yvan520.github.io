# 卡片大全

> 测试服数据尚未公开，以下为基于 RO 经典设定的卡片系统介绍和推测数据。正式上线后将持续更新。

## 卡片系统介绍

卡片是 RO 系列的经典系统，可插入装备孔位获得额外属性加成。每件装备最多可插1张卡片（部分高级装备可能有2孔）。

### 卡片部位

| 部位 | 可插卡装备 | 效果方向 |
|------|-----------|---------|
| 武器卡 | 武器 | 攻击增伤、属性附魔、种族增伤 |
| 铠甲卡 | 铠甲 | HP增加、减伤、属性抗性 |
| 披肩卡 | 披肩 | 回避、减伤、属性抗性 |
| 鞋子卡 | 鞋子 | HP/SP回复、移动速度、血量 |
| 头盔卡 | 头盔 | 属性点、SP上限、特殊效果 |
| 饰品卡 | 饰品 | 稀有特殊效果 |

### 卡片品质

| 品质 | 颜色 | 掉落来源 |
|------|------|---------|
| 普通 | 白 | 普通怪物掉落 |

## 卡片搭配原则

1. **同类叠加**：多张同类百分比卡片效果相加（如两张大嘴鸟卡 = HP+20%）
2. **属性克制**：根据练级地图选择对应属性卡（如不死系地图用圣属性卡）
3. **预算优先**：白卡容易获取，蓝卡需要刷精英，紫/金卡为毕业目标
4. **PVP专用**：人形系增伤/减伤卡片在GVG中效果显著
