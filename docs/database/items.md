# 装备列表

> 测试服数据尚未公开，以下为基于官方预告片和已知信息的装备类型概览。正式上线后将持续更新具体数值。

## 装备部位

| 部位 | 说明 | 示例 |
|------|------|------|
| 武器 | 决定基础攻击力和技能效果 | 长剑、法杖、弓、匕首、钝器、书 |
| 铠甲 | 提供物理防御 | 铁板甲、长袍、皮甲 |
| 披肩 | 提供回避和额外防御 | 斗篷、披风 |
| 鞋子 | 提供移动速度和 HP | 长靴、皮鞋、金属靴 |
| 头盔 | 头部防具，提供 SP/属性 | 金属头盔、魔法帽 |
| 饰品 | 提供特殊属性加成 | 戒指、项链、耳环 |
| 盾牌 | 副手装备，提供格挡 | 圆盾、钢盾、魔法盾 |

## 装备品级

推测沿用 RO 经典设定，装备按颜色分级：

| 品级 | 颜色 | 获取方式 |
|------|------|----------|
| 普通 | 白 | 怪物掉落/商店购买 |
| 强化 | 绿 | 精英怪物/任务 |
| 稀有 | 蓝 | BOSS/副本 |
| 史诗 | 紫 | 高难副本/制作 |
| 传说 | 橙 | 顶级团本/赛季奖励 |

## 获取途径

- 怪物掉落（普通怪/精英怪/MVP BOSS）
- 副本奖励（十人团队本、百人娱乐本）
- 制作系统（收集材料打造）
- 交易所/摆摊（玩家间交易）
- 赛季奖励（赛季制排名奖励）
