# 装备列表

![RO3 装备系统](/images/prontera-compare3.jpg)

> 测试服数据尚未公开，以下内容基于官方预告片、经典RO设定和已知信息整理。正式上线后将持续更新具体数值。

## 装备部位

| 部位 | 说明 | 示例 |
|------|------|------|
| 武器 | 决定基础攻击力和技能效果 | 长剑、法杖、弓、匕首、钝器、书 |
| 铠甲 | 提供物理防御 | 铁板甲、长袍、皮甲 |
| 披肩 | 提供回避和额外防御 | 斗篷、披风 |
| 鞋子 | 提供移动速度和 HP | 长靴、皮鞋、金属靴 |
| 头盔 | 头部防具，提供 SP/属性 | 金属头盔、魔法帽 |
| 饰品 | 提供特殊属性加成 | 戒指、项链、耳环 |
| 盾牌 | 副手装备，提供格挡 | 圆盾、钢盾、魔法盾 |

## 获取途径

- **怪物掉落**：普通怪/精英怪/MVP BOSS
- **副本奖励**：十人团队本、百人娱乐本
- **制作系统**：铁匠制作（收集材料打造）
- **交易所/摆摊**：玩家间自由交易
- **赛季奖励**：赛季制排名奖励
- **任务奖励**：主线/支线/转职任务

## 装备成长路线参考

```
Lv.1-20:  新手装备 (任务赠送)
Lv.20-40: 商店装备 + 任务绿装
Lv.40-60: 副本蓝装 + 制作装备
Lv.60-80: 精英副本装备
Lv.80-99: 毕业装备 (史诗/传说)
```
