# 弓箭手毕业配装推荐

![RO3 弓箭手配装](/images/prontera-compare1.jpg)

**版本：v1.0.2**

## 核心属性优先级

**暴击弓流**：AGI > LUK > DEX > STR
**敏弓流**：AGI > DEX > LUK > VIT
**陷阱流**：INT > DEX > VIT

## 暴击弓配装（推荐）

弓箭手最强的输出流派，依靠高暴击率和锐利射击打出爆炸伤害。

| 部位 | 推荐装备 | 精炼目标 |
|------|---------|---------|
| 武器 | +8 猎弓 / 角弓 | ATK + 暴击伤害 |
| 头盔 | +8 苹果头饰 / 猫耳贝雷帽 | DEX + 暴击 |
| 铠甲 | +6 羽翼战甲 | 暴击 + 闪避 |
| 披风 | +8 箭术斗篷 | 远程攻击 + 暴击 |
| 鞋子 | +6 猎人之靴 | AGI + 闪避 |
| 饰品1 | 弓箭手套环 | 远程攻击 + DEX |
| 饰品2 | 幸运项链 | LUK + 暴击 |

## 挂机（Auto-Battle）设置建议

弓箭手是最适合挂机的职业之一，推荐设置：

```
技能循环：锐利射击 → 双重射击 → 普攻
拾取设置：全部拾取
HP阈值：70% 喝药
SP阈值：30% 坐地恢复
```

## 练级装备过渡路线

| 等级段 | 武器 | 地点 |
|-------|------|------|
| 1-30 | 短弓 → 猎弓 | 南门 |
| 31-60 | +4 十字弓 | 斐杨森林 |
| 61-80 | +6 十字弓 → 角弓 | 兽人地下洞窟 |
| 81-99 | +8 猎弓 / 角弓 | 妙勒尼/古城 |

> **提示**：弓箭手是远程物理职业，保持距离是最重要的生存手段。装备优先升武器到高精炼，防具可以慢慢补。暴击流虽然造价较高，但DPS远超敏弓流。
