# 牧师毕业配装推荐

![RO3 牧师配装](/images/prontera-church.jpg)

**版本：v1.0.2**

## 核心属性优先级

**纯奶路线**：INT > VIT > DEX > AGI
**驱魔路线**：INT > DEX > STR > VIT
**辅助路线**：INT > DEX > VIT > AGI

## 牧师装备哲学

### 为什么牧师是F2P首选
1. **不需要高强武器**：治疗量与ATK无关，低强武器也能刷
2. **组队永远缺牧师**：供不应求，装备差的牧师也有人组
3. **生存优先**：活着才能治疗，优先堆VIT和HP

### 配装优先级
```
治疗量 > 生存 > SP回复 > 施法速度
```

### 省钱技巧
- 武器用普通白板即可，不需要高精炼
- 防具精炼到+6够用
- 饰品优先INT属性，便宜又实用
- 卡片选功能卡（HP/SP）不选稀有卡

## 装备过渡路线

| 等级段 | 武器 | 防具 |
|-------|------|------|
| 1-30 | 木杖 → 圣职法杖 | 布袍 → 圣职者长袍 |
| 31-60 | +4 圣职法杖 | 圣职长袍 → 精炼长袍 |
| 61-80 | +6 治愈之杖 | 精炼长袍 +4 全防具 |
| 81-99 | +8 圣者法杖 | +6 全防具 |

> **核心建议**：牧师是最省钱也最好组队的职业。把省下来的Zeny投资到小号上，一奶一打手组合是最优解。
