# 牧师（推荐组队玩家/零氪）

牧师是组队必备职业，不需要输出装备，零氪也能玩得很舒服，组队需求极高。玩牧师的玩家永远不愁找不到队伍。

## 技能加点

**1-10 级**：点满「治愈术」（核心治疗技能），「天使之护」点 5 级（加防御）

**11-30 级**：点满「加速术」（组队神技，加移速和攻速），「天使之护」点满

**31-60 级**：点满「复活术」（救死扶伤，组队必点），「神圣之光」点满（唯一输出技能，打不死系用）

**61-99 级**：点满「治愈之光」（群疗），「天使之障壁」点满（加全队魔防），剩余点「冥想」（回蓝速度）

## 转职任务流程（20级转职）

1. 普隆德拉教堂找「大主教」（坐标 140,90），接取任务
2. 向教会捐赠 10 万z（可交易，提前准备）
3. 对 NPC 使用 100 次「治愈术」（脱装备降低 SP 消耗反复使用即可）
4. 完成任务，获得牧师资格

## 各等级段练级点

- **1-20 级**：跟着队伍混，负责加血和加 buff（治愈术+加速术）
- **21-60 级**：组剑士/法师队伍，自己负责治疗和 buff，经验分成
- **61-99 级**：高级副本治疗位，热门组队职业，永远缺牧师

## 配装思路

- **武器**：高 INT 法杖（提升治疗量）
- **防具**：高 DEF 铠甲（生存优先）
- **饰品**：回蓝属性优先

## 组队技巧

- 开怪前先给全队上「加速术」和「天使之护」
- 坦克掉血到 70% 再治疗，避免过量治疗浪费 SP
- 复活术优先给治疗/输出，坦克最后拉
- BOSS 战注意走位躲技能，你活着队伍才安全

## 省钱攻略

零氪牧师玩法：
- 不需要高强武器（治疗量跟武器无关）
- 不需要极品防具（有队友帮你拉怪）
- 学会后还可以带小号收费，赚外快
