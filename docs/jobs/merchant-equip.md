# 商人毕业配装推荐

![RO3 商人配装](/images/prontera-guild.jpg)

**版本：v1.0.2**

## 核心属性优先级

**打钱流**：STR > DEX > LUK > AGI
**制作流**：DEX > INT > LUK > VIT
**战斗流**：STR > VIT > DEX > AGI

## 打钱流配装（推荐）

商人的核心玩法，最大化负重、买卖折扣和挂机效率。

| 部位 | 推荐装备 | 精炼目标 | 备注 |
|------|---------|---------|------|
| 武器 | +6 铁锤 / 链锤 | ATK | 便宜够用就行 |
| 头盔 | +4 小丑帽 | 无 | 增加掉宝率 |
| 铠甲 | +4 冒险外套 | 无 | 增加负重 |
| 披风 | +4 斗篷 | 无 | 聊胜于无 |
| 鞋子 | +4 长靴 | HP | 增加生存 |
| 饰品1 | 力量戒指 | STR | 增加负重 |
| 饰品2 | 力量戒指 | STR | 增加负重 |
| 盾牌 | +4 圆盾 | 无 | 偶尔需要抗怪 |

### 核心技能
- 负重量提升（满）：增加携带量
- 低价收购（满）：降低采购成本
- 高价出售（满）：提高卖店收益
- 手推车（满）：额外携带空间

## 商人配装哲学

商人的装备定位与战斗职业完全不同：

1. **够用就行**：商人不靠装备打伤害，装备够打材料怪即可
2. **优先功能装**：增加负重、掉宝率、折扣的功能装 > 战斗属性
3. **投资手艺**：把Zeny花在制作技能上，回报率远高于战斗装备
4. **备一套打钱装**：永远保留一套专门挂机打材料的低成本装备

> **提示**：商人最推荐的玩法是「主号战斗，商人小号打钱」。商人本身战斗能力有限，不要在上面投入太多战斗装备。
