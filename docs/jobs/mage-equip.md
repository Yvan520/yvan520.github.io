# 法师毕业配装推荐

![RO3 法师配装](/images/prontera-street.jpg)

适用版本：v1.0.2

法师群攻能力最强、升级最快，配装核心：**优先堆魔法攻击、魔法穿透，其次堆蓝量和冷却缩减**。

## 平民零氪配装（总造价 < 10万z）

适合零氪/新手，装备均可通过刷怪、任务、商店购买获得。

### 武器：+4 魔法杖（任务奖励）
主线任务 20 级奖励，魔法攻击 +85，足够用到 50 级。

### 头部：+3 魔法帽（商店购买）
普隆德拉道具店购买，魔法攻击 +12，魔法防御 +8。

### 衣服：+3 魔法长袍（古城副本掉落）
古城副本普通难度掉落，魔法攻击 +15，蓝量 +100。

### 饰品：魔法戒指 ×2（蚂蚁洞掉落）
蚂蚁洞刷蚂蚁卵掉落，每个魔法攻击 +8。

### 卡片搭配：波利卡 ×2 + 绿棉虫卡 ×2
波利卡（武器/头部）：魔法攻击 +5；绿棉虫卡（衣服/饰品）：蓝量 +50。

**属性加点**：INT 满 → DEX 30 → VIT 20 → 剩余 AGI

## 氪金毕业配装（总造价 ≈ 500元）

适合微氪/氪金玩家，追求极限输出。

### 武器：+10 红莲魔法杖 💰
魔法攻击 +220，火属性魔法伤害 +15%。

### 头部：+10 智慧头冠 💰
魔法攻击 +35，INT +10，冷却缩减 +5%。

### 衣服：+10 神秘法袍 💰
魔法攻击 +40，魔法防御 +30，受击 10% 概率触发「魔法盾」。

### 饰品：魔力手镯 ×2 + 冷却戒指 ×2 💰
魔力手镯魔法攻击 +25/个，冷却戒指冷却缩减 +8%/个。

### 卡片搭配：邪派浪人卡 ×4 + 金属波利卡 ×2 💰
邪派浪人卡：魔法穿透 +10/个；金属波利卡：魔法攻击 +15/个。

**属性加点**：INT 满 → DEX 50 → 剩余全 AGI

## 各阶段过渡建议

- **1-30 级**：任务送的魔法杖 + 商店基础装备
- **30-60 级**：古城副本衣服 + 蚂蚁洞饰品
- **60-99 级**：攒钱买红莲魔法杖，逐步替换氪金装备
- **毕业**：全套 +10 氪金装备 + 邪派浪人卡，魔法攻击突破 800
