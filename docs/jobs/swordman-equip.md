# 剑士毕业配装推荐

**版本：v1.0.2**

## 核心属性优先级

**坦克路线**：VIT > DEF > HP > AGI
**输出路线**：STR > AGI > DEX > VIT

## 练级装备过渡路线

| 等级段 | 武器 | 防具 |
|-------|------|------|
| 1-30 | 新手剑 → 突袭之剑 | 新手套 → 铁盔+锁子甲 |
| 31-60 | 突袭之剑 → 厚刃剑 | 锁子甲 → 钢铁锁子甲 |
| 61-80 | 厚刃剑 → 战斗长剑 | 钢铁锁子甲 → 精炼防具 |
| 81-99 | 战斗长剑 / 双手巨剑 | 毕业配装过渡 |

> **提示**：剑士作为F2P首选职业，坦克路线的装备需求相对较低。优先投资武器和盾牌的精炼，生存能力优先于输出。
