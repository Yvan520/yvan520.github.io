# 公会系统完全指南

公会是RO3的核心社交组织，加入一个活跃公会将极大提升你的游戏体验。

## 公会基础

### 创建公会

| 条件 | 要求 |
|------|------|
| 等级要求 | Lv.30+ |
| 费用 | 50,000 Zeny |
| 初始人数 | 至少3人 |
| 冷却时间 | 创建后7天内不可解散 |

**创建步骤**：
1. 前往主城（普隆德拉）找到公会管理员
2. 提交创建申请并缴纳费用
3. 邀请至少2名成员加入
4. 设置公会名称和徽章

### 加入公会

- 通过公会列表搜索申请
- 接受公会成员的邀请
- 通过世界频道招募信息加入

## 公会管理

### 职位体系

| 职位 | 权限 |
|------|------|
| 会长 | 全部权限 |
| 副会长 | 审批入会、发起GVG、管理仓库 |
| 精英 | 邀请成员、使用公会技能 |
| 成员 | 基本权限 |
| 见习 | 无特殊权限 |

### 公会贡献

贡献是公会系统的核心货币，可通过以下方式获得：

| 方式 | 贡献值 | 说明 |
|------|--------|------|
| 每日签到 | 10点/天 | 最稳定的来源 |
| 公会任务 | 20-50点/次 | 每日可做3次 |
| GVG参与 | 100点/次 | 获胜翻倍 |
| 捐献Zeny | 1点/1,000 Zeny | 每日上限10,000 Zeny |
| 捐献材料 | 视材料价值而定 | 常见材料即可 |

### 公会商店

贡献值可在公会商店兑换：

- 经验药水（+30%经验，持续1小时）
- 精炼保护卷轴
- 公会限定头饰/外观
- 稀有材料

### 公会技能

公会会长可消耗公会资金学习/升级技能：

| 技能名 | 效果 | 最大等级 |
|--------|------|---------|
| 经验加成 | 全成员经验获取+ | 10级（+20%） |
| 负重增加 | 全成员负重量+ | 5级（+500） |
| HP增加 | 全成员最大HP+ | 10级（+15%） |
| SP增加 | 全成员最大SP+ | 10级（+15%） |
| GVG攻击 | GVG中攻击力+ | 5级（+10%） |
| GVG防御 | GVG中防御力+ | 5级（+10%） |

## GVG公会战

![RO3 骑士公会场景](/images/prontera-guild.jpg)

详见 [GVG攻城战攻略](/guide/gvg-strategy)

### 公会战时间

- **常规GVG**：每周三、六 20:00-21:00
- **领土战**：每周日 20:00-21:30
- **赛季决赛**：赛季末周六

### 公会战组织

**战前准备**：
1. 提前30分钟公会频道集合
2. 分配职业编队（坦克队/输出队/治疗队/骚扰队）
3. 检查装备和药水储备
4. 确认语音频道（推荐Discord/游戏内语音）

## 公会收入来源

| 来源 | 收入 | 分配方式 |
|------|------|---------|
| 成员捐献 | Zeny/材料 | 直接入公会仓库 |
| GVG获胜奖励 | Zeny + 公会经验 | 系统发放 |
| 领地税收 | 领地资源 | 领地主公会专属 |
| 赛季奖励 | 限定道具 | 全成员发放 |

## 公会外交

RO3引入了公会外交系统：

- **结盟**：与其他公会建立同盟关系
- **宣战**：向敌对公会宣战
- **中立**：保持中立状态
- **领地协议**：关于领土的互不侵犯条约

## 公会管理建议

1. **活跃管理**：清理7天未上线的成员
2. **贡献制度**：设置每周最低贡献要求
3. **GVG考勤**：记录GVG参与度，作为奖励依据
4. **新人培养**：安排老人带新人，稳定公会梯队
5. **外交维系**：保持与同盟公会的沟通

> **一句话**：一个好的公会 = 活跃的管理 + 公平的制度 + 热闹的聊天频道。
