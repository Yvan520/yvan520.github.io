# 装备制作与精炼指南

## 制作系统

RO3 的装备制作系统由商人转职铁匠后解锁，可以制作各种武器、防具和饰品。

### 制作流程

1. **学习配方**：通过技能书或 NPC 学习装备配方
2. **收集材料**：从怪物掉落、采集、交易所获得材料
3. **制作装备**：在铁匠铺使用相应技能制作
4. **成品出售**：制作出的装备可以自用或摆摊出售

### 制作等级

| 等级 | 可制作装备 | 需求铁匠技能等级 |
|------|-----------|----------------|
| 初级 | 白色品质武器/防具 | 1-3 级 |
| 中级 | 绿色品质武器/防具 | 4-6 级 |
| 高级 | 蓝色品质武器/防具 | 7-9 级 |
| 大师 | 稀有材料转化 | 10 级 |

## 精炼系统

精炼是提升装备属性的核心途径，用精炼材料对装备进行强化。

### 精炼规则

- **精炼等级**：+1 到 +15
- **精炼材料**：铝（防具）/ 神之金属（武器）
- **精炼失败**：+6 以下失败不掉级，+7 以上失败可能掉级或损坏

### 精炼概率参考

| 精炼等级 | 成功率（估算） |
|----------|---------------|
| +1 → +4 | 100% |
| +5 → +6 | 约 60% |
| +7 → +9 | 约 40% |
| +10 → +12 | 约 20% |
| +13 → +15 | 约 10% |

### 精炼技巧

- **准备多件**：准备 3-5 件同装备轮流精炼
- **垫子法**：先用低级装备试概率，感觉"运气好"再上主装备
- **保护道具**：高精炼建议使用保护卷轴（防损坏）
- **时机选择**：服务器人数少的时段精炼，延迟更低

## 属性附魔

部分装备可以通过附魔系统附加额外属性：

| 附魔类型 | 效果 | 适用部位 |
|----------|------|----------|
| 力量附魔 | +STR | 武器/饰品 |
| 敏捷附魔 | +AGI | 武器/披肩 |
| 智力附魔 | +INT | 武器/鞋子 |
| 体质附魔 | +VIT | 铠甲/盾牌 |
| 灵巧附魔 | +DEX | 武器/饰品 |
| 幸运附魔 | +LUK | 饰品 |

## 搬砖推荐

通过制作和精炼系统赚钱是最稳定的收入来源：
1. **收购低价材料**制作热门装备出售
2. **接单精炼**：帮其他玩家精炼装备收手续费
3. **倒卖材料**：低价囤积精炼材料，高价时出手
