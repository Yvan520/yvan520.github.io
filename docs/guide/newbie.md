# 新手入坑完全指南

## 游戏基础信息

| 项目 | 内容 |
|------|------|
| 游戏名称 | RO3 仙境传说3（Ragnarok Online 3） |
| 开发商 | Gravity × JoyMaker |
| 类型 | MMORPG（跨平台 PC / iOS / Android） |
| 发行时间 | 2026年（全球同步上线） |
| 收费模式 | 免费游玩 + 内购 |
| 语言 | 简中 / 繁中 / 英文 / 日文等多语言 |

![RO3 游戏画面预览](/images/prontera-church.jpg)

## 设备要求

### PC 最低配置
- 系统：Windows 10 64-bit
- CPU：Intel i5 或同等
- 内存：8GB
- 显卡：GTX 960 或同等

### 手机最低配置
- iOS：iPhone 11 或更新机种
- Android：骁龙 845 / 麒麟 980 或同等，6GB 内存

## 开局流程

### 第一步：下载游戏
1. 官网 https://ro3global.com 注册账号
2. 选择 PC 下载或手机应用商店下载
3. 安装完成后启动器更新

### 第二步：创建角色
1. 选择服务器（建议选最新服，人多且经济活跃）
2. 选择职业（参考 [职业选择推荐](/guide/job-pick)）
3. 自定义外观（发型、脸型、肤色等）

### 第三步：新手任务（1-30级）
1. 跟随主线任务指引，熟悉基本操作
2. 学会使用技能、吃药、装备更换
3. 10级时学习第一个主动技能
4. 20级可接取转职任务
5. 建议新手先练到 25 级再转职

### 第四步：日常活动（30级后）
- **每日副本**：经验副本 3 次
- **公会任务**：贡献度任务
- **限时活动**：世界 BOSS / 护送
- **挂机练级**：找对应等级地图挂机

## 必知要点

### 1. 赛季制
RO3 采用赛季制（每赛季 3-4 个月），赛季结束后：
- 角色数据保留
- 重新开启新赛季内容
- 赛季奖励仅当赛季可获取

### 2. 自动战斗
- 自动战斗效率约为手动的 70%-80%
- 日常练级可以挂机解决
- BOSS 战 / GVG 需要手动操作

### 3. 经济系统
- **Zeny**：基础货币，怪物掉落/任务获得
- **绑定 Zeny**：绑定的货币，用于绑定交易
- **信用评分**：交易信用体系，影响摆摊权限

### 4. 装备成长
- 打怪掉落 → 装备制作 → 精炼强化 → 卡片镶嵌
- 详见 [装备制作与精炼指南](/guide/crafting)

## 省钱攻略

- **零氪推荐职业**：剑士、牧师
- **微氪推荐职业**：法师、刺客
- **不推荐的消费**：开服直接抽卡（等赛季中期价格稳定再入手）
- **必买项目**：月卡（如果有）、仓库扩展

## 每日必做清单

| 等级区间 | 必做任务 |
|----------|----------|
| 1-30 级 | 主线任务、转职任务 |
| 30-60 级 | 每日副本 ×3、公会任务、挂机练级 |
| 60-99 级 | 高级副本、世界 BOSS、GVG、摆摊交易 |

## 常见误区

1. **不要急着转职**：20 级就转职会导致技能点不够，前期打怪吃力，建议 25+ 级再转
2. **不要乱点技能**：技能点有限，建议按攻略加点，否则后期洗点需要花钱
3. **不要忽视生活技能**：采集、制作、钓鱼等生活技能是稳定的收入来源
4. **不要单刷高难本**：RO3 强调组队协作，组队效率远高于单刷
5. **不要囤积低级材料**：低级材料价格会快速贬值，及时出手换 Zeny
