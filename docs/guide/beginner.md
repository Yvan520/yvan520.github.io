# 开服必看：萌新避坑指南

::: tip 基于测试服数据整理，以正式服为准
:::

## 开局建议

- **跟着主线走**，前 30 级主线给的经验足够
- **别乱卖材料**，很多任务物品后期买不到
- **加点先规划**，RO3 属性点给得很吝啬

## 服务器选择

测试服反馈：人多选推荐服，想拿奖励选新服。

## 新手三小时清单

- [ ] 跟主线到 10 级
- [ ] 领新手礼包
- [ ] 加入公会（有公会任务经验加成）
- [ ] 加攻略 Q 群获取实时信息
