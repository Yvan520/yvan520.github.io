# PvP竞技场与对战系统

除了大规模GVG攻城战外，RO3还提供了多种小规模PvP玩法，让玩家在不同场景中体验对抗乐趣。

## PvP模式一览

| 模式 | 规模 | 说明 | 开放时间 |
|------|------|------|---------|
| 竞技场1v1 | 单人 | 公平对决，纯技术较量 | 全天开放 |
| 竞技场3v3 | 小队 | 三人组队战术对抗 | 全天开放 |
| 开放世界PVP | 无限制 | 特定地图自由PK | 指定时段 |
| GVG攻城战 | 100v100 | 公会大规模团战 | 每周三、六 |
| 领土争夺战 | 公会联盟 | 多公会领地争夺 | 每周日 |

## 竞技场1v1

### 基本规则
- **等级匹配**：按等级区间匹配对手
- **装备平衡**：提供标准装备模板（可选）
- **时间限制**：每场5分钟
- **胜负判定**：击杀对方/时间到血量百分比高者胜

### 职业1v1强度排行（推测）

| 梯队 | 职业 | 优势 |
|------|------|------|
| S | 刺客 | 高爆发、隐身偷袭 |
| A | 巫师 | 远程压制、控制技能 |
| A | 猎人 | 风筝战术、陷阱控制 |
| B | 骑士 | 高生存、磨血战术 |
| B | 牧师 | 无限续航、消耗战 |
| C | 商人 | 1v1能力最弱 |

### 1v1技巧
1. **了解对手职业**：不同职业有不同应对策略
2. **技能预判**：观察对方动作预判技能
3. **走位拉扯**：近战贴脸、远程保持距离
4. **技能循环**：不要一键甩光所有技能

## 竞技场3v3

### 推荐配置

| 阵容类型 | 配置 | 说明 |
|---------|------|------|
| 铁三角 | 坦克+治疗+输出 | 最稳阵容，容错率高 |
| 双输出+治疗 | 输出x2+治疗 | 爆发高，考验治疗 |
| 三输出 | 输出x3 | 纯暴力，看谁先秒谁 |
| 控制流 | 巫师+猎人+刺客 | 控制链秒人 |

### 3v3战术
1. **集火目标**：优先击杀治疗/脆皮输出
2. **控制链**：先手控制 → 爆发输出 → 收割
3. **保护治疗**：治疗是3v3的核心
4. **地形利用**：利用障碍物规避伤害

## 开放世界PVP

### 规则
- **PVP地图**：特定野外地图开放自由PK
- **安全区**：主城和低级地图不可PK
- **惩罚机制**：击杀普通玩家会扣除声望值
- **悬赏系统**：击杀红名玩家可获得奖励

### PVP地图分级

| 等级段 | PVP地图 | 说明 |
|-------|---------|------|
| 30-60 | 妙勒尼山脉 | 低风险PVP |
| 60-80 | 古城外围 | 中风险PVP |
| 80-99 | 古城深处 | 高风险、高回报 |

## 竞技场奖励

### 赛季奖励

| 排名段位 | 奖励 |
|---------|------|
| 钻石（前10%） | 限定称号 + 赛季限定外观 + 大量荣誉点 |
| 黄金（前30%） | 赛季外观 + 荣誉点 |
| 白银（前60%） | 荣誉点 |
| 青铜（参与奖） | 少量荣誉点 |

### 荣誉点兑换

荣誉点是PvP专属货币，可兑换：

- PvP专属装备
- PvP强化卡片
- 外观道具
- 药水/消耗品

## PvP属性推荐

| 职业 | PvP优先属性 | 说明 |
|------|-----------|------|
| 骑士 | VIT > DEF > HP | 站得住才能保护队友 |
| 巫师 | MATK > 冷却 > MDEF | 爆发优先 |
| 刺客 | 暴击 > 攻速 > 闪避 | 一击必杀 |
| 猎人 | 远程攻击 > 暴击 > 闪避 | 放风筝 |
| 牧师 | HP > 治疗量 > 施法速度 | 活着才能奶 |
| 商人 | STR > VIT > DEF | 近战硬刚 |

> **提示**：PvP和PvE的配装思路完全不同，建议准备一套专门的PvP装备。刺客和法师在竞技场中表现亮眼，但需要较高的操作水平。
