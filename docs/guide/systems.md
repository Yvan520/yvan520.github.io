# RO3 核心系统介绍

了解 RO3 区别于其他 MMO 的特色系统。

## 赛季制

每个赛季 3-4 个月，推出新的职业流派与玩法内容。

- 「赛」：领地争霸战等竞争玩法
- 「季」：资料片式的内容扩充
- 新玩家随时可加入，差距不大
- 赛季结束后可投票复刻经典赛季

## 多元宇宙

新角色「布拉吉丝」带领玩家穿越平行宇宙。

- 每个世界拥有独特的文明风貌与挑战
- 每次穿越带来新的战斗体验和成长路径
- 每个平行世界赋予角色新的职业特质
- 随时选择新世界重新启程

## GVG 攻城战

- 支持 100v100 同场景战斗
- 终极目标：千人同场景攻城战
- 使用攻城车、云梯、炮台、机甲等器械
- 需要团队协作，无法一人攻城
- 粮草运输、结盟等策略要素

## 百人副本

以「鲲」为主题的 Party Game 副本，强调娱乐性。

## 十人副本

不追求输出，强调互动性：玩家×玩家、玩家×场景、玩家×Boss。

## 自由交易

经典「摆摊」系统回归，新增信用评分机制。

## 自动战斗

自动战斗效率约为手动的 70%-80%，解决日常练级负担。
