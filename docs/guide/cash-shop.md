## 购买优先级

### 必买（F2P也要存钻买）
1. **月卡** - 性价比最高的投入
2. **通行证** - 大量资源回报
3. **精炼保护** - 装备不碎保障

### 推荐买
1. **每日特惠包** - 材料+药水
2. **成长礼包** - 升级送资源
3. **外观礼包** - 有属性加成的头饰

### 不建议买
1. **直接买装备** - 副本/制造更划算
2. **抽卡包** - 概率坑
3. **经验书大礼包** - 慢慢玩不缺

## 月卡性价比分析

```
月卡价格：30 RMB
获得：300钻石 + 每日100钻石
月总计：300 + 30×100 = 3300钻石
每RMB：110钻石
```

对比直充648档位（约10钻石/RMB），月卡的性价比是直充的10倍以上。

> **建议**：如果只打算花少量钱，月卡 + 通行证是最优组合。

## 零氪玩家（F2P）攻略

### 日常资源积累

| 项目 | 每日钻石收入 | 说明 |
|------|------------|------|
| 每日签到 | 20-50 | 累积签到 |
| 日常任务 | 30-50 | 完成所有日常 |
| 竞技场 | 20-50 | 每日5场 |
| 公会贡献 | 10-20 | 公会任务 |
| **日常总计** | **80-170** | 稳定收入 |

| 项目 | 每周钻石收入 | 说明 |
|------|------------|------|
| GVG参战 | 100-300 | 胜场更多 |
| 周常副本 | 200-400 | 团队副本 |
| 赛季排名 | 500-1000 | 赛季结算 |
| **周总计** | **800-1700** | 额外收入 |

### F2P钻石用途（按优先级）

1. **背包扩展** - 600钻（一次性）
2. **仓库扩展** - 400钻（一次性）
3. **精炼保护** - 按需购买
4. **每日体力** - 50钻/次（量力而行）
5. **外观** - 最后考虑

### F2P避坑指南

| 不要做的事 | 原因 |
|-----------|------|
| 抽卡抽装备 | 钻石换概率不划算 |
| 买药水 | 日常产出够用 |
| 买经验书 | 等级早晚会满 |
| 买材料 | 采集/掉落即可获得 |

### F2P推荐职业

| 职业 | 原因 |
|------|------|
| **剑士** | 装备要求低，坦度在线 |
| **牧师** | 组队需求大，装备需求不高 |
| **法师** | AOE练级效率高 |

## 赛季通行证策略

### 免费版
- 优先完成赛季任务
- 攒赛季币兑换核心装备
- 不要强求100级

### 付费版
- 通行证越早买越好，充分利用每日任务
- 满级后可获得额外赛季币
- 核心奖励在60级、80级、100级

## 常见问题

**Q：0氪能玩吗？**
A：完全可以。RO3的核心玩法（GVG/副本/PVP）F2P玩家都能参与。

**Q：0氪和氪金差距大吗？**
A：差距主要在精炼度和装备进度，技术可以弥补一部分，但PVP中差距明显。

**Q：月卡什么时候买最划算？**
A：赛季初买，充分利用整个赛季的每日奖励。

> **核心原则**：RO3的核心是技术和团队配合，装备是次要因素。F2P玩家只要坚持日常，完全可以体验游戏所有内容。
