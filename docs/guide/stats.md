# 属性（STAT）系统详解

![RO3 属性系统](/images/prontera-north.jpg)

RO3继承了RO经典的属性系统，六项基础属性的合理分配决定了角色的发展方向。

## 六项基础属性

### STR（力量）

| 项目 | 内容 |
|------|------|
| **主要影响** | 物理攻击力、负重上限 |
| **适合职业** | 剑士、刺客、商人 |
| **加点优先级** | 物理输出职业 > 坦克 > 法系职业 |
| **每点收益** | ATK +2, 负重 +30 |

**适合场景**：
- 物理近战输出（骑士、刺客）
- 需要负重的职业（商人）
- 追求普攻伤害的BD

### AGI（敏捷）

| 项目 | 内容 |
|------|------|
| **主要影响** | 攻击速度、闪避率 |
| **适合职业** | 刺客、弓箭手、剑士 |
| **加点优先级** | 攻速职业 > 闪避坦 > 其他 |
| **每点收益** | 攻速 +1%, 闪避 +1 |

**适合场景**：
- 追求攻速的暴击流（刺客、弓箭手）
- 闪避坦克
- 挂机自动战斗

### VIT（体力）

| 项目 | 内容 |
|------|------|
| **主要影响** | 最大HP、物理防御、HP回复 |
| **适合职业** | 剑士、牧师、所有职业 |
| **加点优先级** | 坦克 > 近战 > 远程 |
| **每点收益** | HP +50, DEF +1, HP回复+ |

**适合场景**：
- 前排坦克
- PvP需要生存的职业
- 任何需要提高容错率的BD

### INT（智力）

| 项目 | 内容 |
|------|------|
| **主要影响** | 魔法攻击力、最大SP、SP回复 |
| **适合职业** | 法师、牧师、贤者 |
| **加点优先级** | 法系职业 > 物理职业不点 |
| **每点收益** | MATK +2, SP +10, SP回复+ |

**适合场景**：
- 魔法输出（巫师、贤者）
- 治疗职业（牧师）
- 需要频繁使用技能的BD

### DEX（灵巧）

| 项目 | 内容 |
|------|------|
| **主要影响** | 命中率、远程攻击力、施法速度 |
| **适合职业** | 弓箭手、法师、所有职业 |
| **加点优先级** | 远程职业 > 法系 > 物理近战 |
| **每点收益** | 命中 +1, 远程ATK +1, 施法速度+ |

**适合场景**：
- 远程物理输出（猎人）
- 需要施法速度的法系
- 任何需要命中的BD

### LUK（幸运）

| 项目 | 内容 |
|------|------|
| **主要影响** | 暴击率、暴击伤害、掉宝率 |
| **适合职业** | 刺客、弓箭手、商人 |
| **加点优先级** | 暴击流 > 打钱流 > 其他 |
| **每点收益** | 暴击率 +0.3%, 暴击伤害 +0.5%, 掉宝率+ |

**适合场景**：
- 暴击流输出（刺客拳刃、弓箭手角弓）
- 打钱/刷宝BD
- 需要暴击触发的技能

## 属性收益规律

### 非线性收益

RO3的属性点收益遵循**递减规律**：

```
1-50点：  高收益期（每点收益100%）
50-80点： 中收益期（每点收益70%）
80-99点： 低收益期（每点收益50%）
```

**策略建议**：
- 主属性点到80即可转点副属性
- 除非是极限BD（如纯VIT坦克），不建议点到99
- 适当补短板属性比极限一项更有效率

### 边际效益举例

以STR为例：

| STR值 | ATK加成 | 每点收益 |
|-------|---------|---------|
| 1→50 | +100 ATK | 2.0 ATK/点 |
| 50→80 | +42 ATK | 1.4 ATK/点 |
| 80→99 | +19 ATK | 1.0 ATK/点 |

> **核心原则**：不要照搬别人的加点方案。根据自己的装备、卡片和玩法风格灵活调整，才是最优解。
