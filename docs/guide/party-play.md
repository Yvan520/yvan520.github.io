# 组队与团队副本攻略

![RO3 普隆德拉街景](/images/prontera-compare3.jpg)

RO3延续了RO强社交的MMO核心，组队是游戏后期最重要的玩法。从日常副本到十人团队副本，合理的队伍配置是通关的关键。

## 组队基础

### 组队加成
- **经验加成**：2人队+10%，3人+15%，4人+20%，5人以上+30%
- **掉落加成**：组队状态下稀有掉落概率提升
- **职业互补**：不同职业组队有隐藏配合收益

### 组队界面
- 使用快捷键 `Ctrl+P` 打开组队面板
- 可设置自动审批/手动审批
- 可按等级范围筛选队员
- 可设置目标副本/活动标签

## 职业搭配原理

### 铁三角阵容

```
坦克 (Tank) → 抗伤害、拉仇恨
    ↕
治疗 (Healer) → 回血、驱散、复活
    ↕
输出 (DPS) → 打伤害、清怪
```

### 推荐队伍配置

#### 5人小队（适合日常/练级）

| 位置 | 职业 | 数量 |
|------|------|------|
| 坦克 | 剑士/骑士 | 1 |
| 治疗 | 服事/祭司 | 1 |
| 近战DPS | 盗贼/刺客 | 1 |
| 远程DPS | 弓箭手/猎人 | 1 |
| 法系DPS | 法师/巫师 | 1 |

#### 10人团队（适合团队副本）

| 位置 | 职业 | 数量 |
|------|------|------|
| 主坦克 | 骑士 | 1 |
| 副坦克 | 十字军 | 1 |
| 主治疗 | 祭司 | 2 |
| 物理DPS | 刺客/猎人/铁匠 | 3 |
| 魔法DPS | 巫师/贤者 | 2 |
| 辅助/自由位 | 诗人/舞娘/流氓 | 1 |

## 十人团队副本

十人团队副本是RO3的核心PvE内容，根据官方预告片和制作人访谈，副本设计强调「沉浸式协作」。

### 已知副本：神之境界（暂定名）

在台北电玩展上展示的「神之境界」副本是首次公开的十人副本。

**基本信息**：
- **人数要求**：10人
- **等级要求**：Lv.60+
- **推荐装备**：蓝装以上
- **每周限制**：每周1次（赛季刷新）

**BOSS机制特点**：
- 融合环境互动（场景机关、地形利用）
- 需要精准的职业配合
- 特定阶段需要特定职业技能处理
- BOSS有多个阶段形态

### 通用副本攻略原则

1. **开荒准备**
   - 全员检查装备耐久度
   - 备足药水（HP大药、SP药、复活叶）
   - 提前了解BOSS机制（看视频/攻略）
   - 分配好各位置职责

2. **战斗分工**
   - 坦克：拉BOSS面向背对团队
   - 治疗：保持全员血量在安全线以上
   - DPS：优先处理BOSS召唤的小怪/机制
   - 指挥：指定1人负责喊技能/提醒走位

3. **灭团应对**
   - 祭司保留复活术CD用于关键时刻
   - 灭团后原地等待，别急着回城
   - 复盘灭团原因，调整战术

## 百人娱乐副本（百人本）

根据制作人专访，RO3还将推出百人规模的娱乐副本（代号「鲲」）。

**特点**：
- 100人同屏战斗
- 派对游戏风格（Party Game）
- 比十人本更轻松、娱乐性更强
- 掉落稀有外观/玩具类道具

## 日常副本：旧古城

**基本信息**：
- 等级要求：Lv.60+
- 队伍人数：4人
- 每日次数：3次
- 经验收益：约800,000/次

**攻略要点**：
- 推荐4人满编队吃经验加成
- 法师AOE清小怪效率最高
- 最后的精英怪需要坦克拉住

## 组队礼仪

### 当队长时
- 明确标注队伍目标（如「古城日常3缺1」）
- 进本前说明掉落分配规则
- 合理分配职业配置
- 遇到新手耐心指导

### 当队员时
- 进队先打招呼
- 确认自己了解副本机制
- 及时吃药，别让治疗一直救你
- 不要抢坦克的仇恨
- 掉落分配遵守规则

## 寻找队友渠道

1. **世界频道喊话**：最直接的方式
2. **公会活动**：公会成员优先组队
3. **好友列表**：加靠谱的玩家好友
4. **自动匹配**：如果游戏有匹配系统

> **核心原则**：一个好队友胜过三个装备好的路人。建立稳定的队友圈子是RO3长期游玩的基石。
