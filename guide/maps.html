传送系统 ​

基础传送 ​

  • 传送阵：各大主城之间有固定传送阵
  • 卡普拉服务：花费Zeny传送到已注册的地图
  • 记忆传送：在特定位置使用记忆道具可快速返回

传送费用计算 ​

传送费 = 基础费 + (角色等级 × 10) + 距离系数
  • 同区域：基础费最低
  • 跨区域：费用x2
  • 特快传送：费用x3（速度更快）

练级路线推荐 ​

Lv.1-20 新手期 ​

路线：普隆德拉南门 → 西门农场 → 妙勒尼山脉

Lv.20-40 成长期 ​

路线：梦罗克沙漠 → 蚂蚁洞穴 → 斐扬森林

Lv.40-60 进阶期 ​

路线：欧克洞窟 → 金字塔 → 海洞

Lv.60-80 高手期 ​

路线：吉芬地下 → 史芬克斯 → 钟塔

Lv.80-99 毕业期 ​

路线：古城 → 深渊峡谷 → 龙之城

传送小贴士 ​

  1. 注册常用地图：在卡普拉处注册常去地图，费用减半
  2. 组队传送：队长传送后队员可免费跟传
  3. 回城卷轴：随身携带回城卷，危急时保命
  4. 传送节省：等级越高传送费越贵，低级时多跑图

提示：新手前20级建议跑图熟悉环境，既省钱又避免错过隐藏任务。
