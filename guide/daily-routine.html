副本（3次）15分钟装备 + 经验旧古城副本，60级后可打
公会签到1分钟公会贡献每天签到攒贡献
领取离线奖励1分钟离线经验下线前挂机可获得

领地争夺战30分钟领土奖励公会活动

高效时间管理方案 ​

上班族版（1小时/天） ​

周一至周五：
  上线 → 签到(1min) → 每日任务(10min) 
  → 副本x3(15min) → 挂机离线(全程) 
  → 下线(总计约25min)

周末：
  补周常副本 + 赛季任务 + GVG活动
  (约2小时)

学生党版（2-3小时/天） ​

上线 → 签到 → 每日任务 → 看板悬赏 
→ 副本x3 → 材料日常 → 挂机刷材料
→ 晚上组队MVP/十人本
→ 下线前挂机离线

肝帝版（5小时+/天） ​

上午：每日任务 + 看板 + 材料日常 + 挂机
下午：副本x3 + 周常 + 赛季任务
晚上：GVG/领地战 + MVP组队 + 十人本
深夜：挂机刷材料 + 摆摊卖货

小贴士 ​

  1. 离线挂机：下线前一定要找好挂机点开启离线战斗
  2. 副本CD：每日副本次数不用完就是损失
  3. 公会活动：找个活跃公会，GVG和领土战奖励丰厚
  4. 组队加成：尽量组队打副本和MVP，经验加成+掉落加成
  5. 别贪多：量力而行，游戏是拿来玩的不是上班

一句话总结：每日三件套（任务+副本+签到）是基本盘，周常+GVG是进阶盘，MVP+十人本是惊喜盘。
